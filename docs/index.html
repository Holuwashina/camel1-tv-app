Camel1 TV app

Watch camel1.tv in its own window, with the promo banners hidden and pop-ups blocked.

This is an unofficial, community-made app. It is not made by or affiliated with Camel1. It simply shows the camel1.tv website. Source code is on GitHub.

Mac Your device

Intel and Apple Silicon. Open the .dmg and drag to Applications.

macOS says the developer can't be verified Right-click the app, choose Open, then Open again. On newer macOS you may also need System Settings, Privacy & Security, then "Open Anyway". This is a one-time step.
Download .dmg

Android Your device

Android 7 and newer. Open the .apk after downloading.

Phone blocks the install Android asks you to allow installs from this source (your browser) the first time. Allow it, then open the file again.
Download .apk

Windows Your device

Windows 10 and 11, 64-bit installer.

Windows SmartScreen warning Click "More info", then "Run anyway". The app isn't code-signed, which is why Windows asks.
Download installer

Linux Your device

AppImage runs anywhere (chmod +x it first). A .deb is also available.

AppImage .deb

iPhone and iPad Your device

Apple doesn't allow apps to be installed from a web page. Use the website instead: open camel1.tv in Safari, tap Share, then "Add to Home Screen".
